# Quellenregister

Für jedes Blatt eine Datei. Jede Zahl, die auf einer Karte steht, hat hier eine Zeile
mit Status. Drei Status, mehr nicht:

| Status | heißt |
|---|---|
| **belegt** | Quelle benannt, Zahl steht dort wörtlich so |
| **abgeleitet** | aus belegten Daten gerechnet — Rechenweg in der Zeile |
| **unbelegt** | steht auf der Karte, ist aber nicht nachgewiesen. Muss ersetzt oder entfernt werden |

Regel fürs Blatt: **unbelegte Angaben werden auf der Karte als solche gekennzeichnet.**
Wenn ein Blatt einmal als Reiseführer erscheint, darf keine unbelegte Zeile mehr übrig sein.

Was hier *nicht* hineingehört: Geometrie aus benannten Datensätzen (OSM, Natural Earth,
Eurostat) — deren Herkunft steht in der Fußzeile des Blattes. Hier stehen die **Aussagen**.
